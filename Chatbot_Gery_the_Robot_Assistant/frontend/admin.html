The token stays in this browser tab and is never stored in the knowledge index.

Where to get the token

On Ubuntu, open a terminal in the NVGS Server folder and run:

sudo cat secrets/gery_admin_token

If that file is missing, run ./scripts/bootstrap-secrets.sh once, then use the generated value above.

Where to configure optional AI

Put the endpoint, model, and switches in the NVGS Server root .env file:

GERY_INGESTION_AI_ENABLED=true GERY_AI_BASE_URL=http://host.docker.internal:1234 GERY_AI_MODEL=your-model-name GERY_ALLOW_LIVE_AI=false

Put only the API key in secrets/gery_ai_api_key. Restart Gery, then click Reprocess all.
